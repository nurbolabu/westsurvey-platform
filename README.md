# WestSurvey · Контроль строительства автодороги (прототип)

Статический прототип платформы для контроля хода строительства дороги в Актюбинской области.

- Вход с выбором роли (в прототипе проверка только в браузере).
- Схема трассы ПК 0 – ПК 200 со статусами пикетов (в рабочей версии будет Mapbox + KML).
- Линейный график готовности слоёв по пикетам.
- Окно пикета: слева шкала конструкции с объёмами по слоям, справа этапы, подрядчик, люди, техника, геодезия, лаборатория, фото и журнал работ.

Все данные демонстрационные (`data.js`).
