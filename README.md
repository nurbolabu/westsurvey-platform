# WestSurvey · контроль строительства автодороги

Платформа WestSurvey и Kazcomservice для контроля хода строительства автодороги в Актюбинской области.

Демо: https://nurbolabu.github.io/westsurvey-platform/

## Что есть

- **Карта на весь экран**: спутник, рельеф и 3D, трасса с пикетами по статусам, участки подрядчиков. Клик по пикету открывает его паспорт.
- **Показатели и линейный график** под картой: готовность против плана, слои по пикетам, активные фронты, отставания.
- **Окно пикета**: поперечный профиль насыпи по слоям, текущий статус, подрядчик и люди, техника, геодезия, лаборатория, фото, журнал.
- **Ввод данных**: отчёты прорабов, геодезические съёмки, протоколы лаборатории, импорт оси трассы из KML/GeoJSON, проектные объёмы из CSV. Всё попадает в факт после подтверждения технадзором.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html`, `styles.css`, `app.js` | интерфейс |
| `config.js` | токен Mapbox и демо-трасса |
| `map.js` | карта (MapLibre GL, тайлы Mapbox или Esri), разбор KML/GeoJSON |
| `data.js` | демо-данные проекта |
| `entries.js` | хранилище внесённых данных (сейчас браузер, далее Supabase) |
| `supabase/migrations/0001_init.sql` | схема базы: PostGIS, таблицы, расчёт пикетов, права |
| `docs/ARCHITECTURE.md` | какие данные нужны для карты, как интегрировать Mapbox, кто что вносит |
| `templates/` | шаблон CSV проектных объёмов и пример KML оси |

## Запуск локально

```
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

Все данные в демо вымышлены.
